# React Bits

Componentes copiados do [React Bits](https://github.com/DavidHDev/react-bits) (David Haz),
variante JS + CSS, commit `e12c221`. Licença em `LICENSE.md`
(MIT + Commons Clause: uso livre no site, sem redistribuir os componentes isoladamente).

- `ScrollReveal`: frase do Sobre na home, revelada palavra a palavra com o scroll
- `SplitText`: títulos das seções e das páginas
- `AnimatedContent`: entrada suave de blocos e cards
- `ShinyText`: brilho nos rótulos em destaque
- `Magnet`: botões que "puxam" o cursor
- `TiltedCard`: foto da página Sobre
